# ⚽ FootballVerse v1

FootballVerse is a modern football platform focused on delivering live football data alongside editorial content. Version 1 is intentionally kept small, fast, and production-ready by focusing only on the core features.

---

# Features

## Football Data

### Live Scores
- Live match scores
- Match status
- Minute-by-minute updates

### Fixtures
- Today's fixtures
- Upcoming fixtures
- Previous match results

### League Standings
- Current league table
- Position
- Points
- Wins
- Draws
- Losses
- Goal Difference

### Match Details

Each match includes:

- **Score**
- **Events**
  - Goals
  - Yellow cards
  - Red cards
  - Substitutions

- **Statistics**
  - Possession
  - Shots
  - Shots on target
  - Corners
  - Fouls
  - Pass Accuracy

- **Lineups**
  - Starting XI
  - Bench
  - Formation

---

### News

### Articles
